# Dynamical odd-string mechanism

**Model role:** inherit the parent research model.

**Inputs:** [idea bank](../../blackboard/ideas.md), [workplan](../../notes/workplan.md), `{{BASE_COMMIT}}`; parent selects one `{{MECHANISM}}`, such as a worldsheet mode, endpoint conversion, or localized defect. Write only `{{OUTPUT_PATH}}`.

**Task:** Define a worldsheet or boundary action for `{{MECHANISM}}` that makes the complete q/qbar or qbar/qbar string an odd fermionic state while a bosonic extended sector exists in the same construction. Derive the parity assignment, one state or pole, and one whole-state probe-current prediction. State how the retained-adjoint fixed-number model arises as a limit or why it fails to do so. Preserve physical endpoint Dirac character and all exact charges.

**Deliverable and stop:** A minimal calculable action and one diagnostic, or an explicit obstruction, in `{{OUTPUT_PATH}}`. Stop after this one mechanism.

**Pitfall:** Renaming an inert spectator as a fermionic string, or inferring short-distance scattering from vanishing classical fermion expectation, does not supply dynamics.
