# Selección de conversación

Este repositorio puede contener múltiples conversaciones, cada una descrita en el `README.md` de la raíz.

Antes de leer los archivos de cualquier conversación, consulta ese README y decide en cuál trabajar, o si corresponde iniciar una conversación nueva. No leas los archivos de las distintas conversaciones para decidir cuál seleccionar. Si la petición y el README no permiten determinar la conversación pertinente, pide aclaración al usuario antes de acceder a sus archivos.

Una vez elegida una conversación existente, lee su `AGENTS.md`, si lo hay, y los archivos necesarios para la tarea. Si se elige una conversación nueva, no leas los archivos de las conversaciones existentes salvo que el usuario solicite utilizarlos.

# Redacción

En las notas, documentos y respuestas de cualquier conversación de este repositorio, las ideas, teorías, modelos y textos se nombran sin atribución personal ni posesivos. Se evitan formas como «your idea», «your theory», «my interpretation» o «the author's model». Se usa la referencia global («the theory», «the brief», «the 2003 text») o la primera persona del plural («we see», «our model»). Los archivos de `sources/` de cada conversación conservan sin cambios el texto recibido.
